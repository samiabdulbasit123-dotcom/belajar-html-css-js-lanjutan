Swap Variabel & Ambil Elemen Array

array destructuring

Sudah tersedia dua variabel let pemainA = "Andi" dan let pemainB = "Budi".

  • Tukar (swap) isi pemainA dan pemainB memakai array destructuring dalam satu baris (tanpa variabel bantu manual).
  • Dari array warnaFavorit = ["Merah", "Biru", "Hijau", "Kuning", "Ungu"], ambil elemen pertama dan ketiga saja pakai destructuring (lewati elemen kedua dengan koma kosong), simpan ke variabel warnaUtama dan warnaKetiga.

object destructuring

Rest Pattern dalam Destructuring

rest pattern

Array nilaiUjian = [100, 70, 85, 90, 60, 75] sudah tersedia (elemen pertama adalah nilai ujian percobaan, sisanya nilai ujian asli).

  • Pisahkan elemen pertama ke variabel nilaiPercobaan, dan sisanya ke variabel nilaiAsli memakai rest pattern (...nilaiAsli) dalam array destructuring.
  • Hitung rata-rata dari nilaiAsli saja (jangan ikutkan nilai percobaan).
  • Lakukan hal serupa untuk object: dari dataSiswa = { nama: "Sinta", kelas: "12A", nilaiMatematika: 95, nilaiFisika: 88, nilaiKimia: 92 }, pisahkan nama dan kelas secara terpisah, lalu kumpulkan sisa properti nilai (mapel-mapel) ke satu object baru bernama nilaiMapel pakai object rest pattern.
  • Tampilkan semua hasil ke #output-rest.
